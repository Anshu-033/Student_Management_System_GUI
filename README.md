# Student Management System - GUI 🎓

A **GUI-based Student Management System** developed using **Java Swing**. The application provides a graphical interface for managing student records and uses **JDBC and SQL** for database connectivity and data management.

## ✨ Features

* Graphical User Interface using Java Swing
* Add student records
* View student information
* Manage student records
* Database connectivity
* Interactive buttons, forms, and tables
* Simple and user-friendly interface

## 🛠️ Technologies Used

* **Java**
* **Java Collections / Core Java concepts**
* **Java Swing**
* **JDBC (Java Database Connectivity)**
* **SQL**
* **MySQL**

## 🗄️ Database

The application uses **MySQL** to store and manage student information.

JDBC is used to establish the connection between the Java application and the database.

## ▶️ How to Run

1. Clone the repository.
2. Open the project in a Java-supported IDE.
3. Make sure MySQL is installed and running.
4. Create the required database and tables.
5. Configure the database connection details in the project.
6. Add the required JDBC driver.
7. Run the main Java class.
